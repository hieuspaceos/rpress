# Phase 4: per-site theme CSS

## Goal

`traveltour-style-custom.css` is a *site-generated* file (WP writes it
into wp-content/uploads per site). Today rpress ships one copy at
`templates/front-css/traveltour-style-custom.css` (+`.scoped.css`) with
absolute `https://aucoeurvietnam.com` asset URLs — every non-aucoeur
site inherits aucoeur's colors/fonts/image references. Import must
carry the site's own copy; serve resolves it per site.

## Findings covered

- `templates/front-css/traveltour-style-custom.css` and
  `traveltour-style-custom.scoped.css` — absolute aucoeurvietnam.com
  URLs inside.
- `src/render_post.rs:377-391` — head-css splice anchors on link ids
  (`traveltour-style-core-css`, `tourmaster-custom-style-css`); the
  `traveltour-style-custom` link href itself is emitted by the base
  template — point it at a per-site path.
- `src/admin/plugins/goodlayers/boot.rs:1534-1538` — Live Mode canvas
  loads `.scoped.css` variants from `/admin/front-css/`; per-site css
  needs a scoped twin generated by the same scoper at import (not a
  manually maintained second file).
- `templates/front-css/*.scoped.css` convention — scoped variant lives
  beside the unscoped file.
- Media/upload carry: import already walks wp-content uploads into
  `media`/site www dirs (verify the exact uploads handling — if
  `traveltour-style-custom.css` lands in `wp-content/uploads` it may
  already be copied as a static file; then the fix is only the template
  href + dropping the repo copy).

## Key insights

- **Source of truth = the site's own file.** If import already mirrors
  uploads to `www/wp-content/uploads/...`, the repo copies of
  `traveltour-style-custom.css` are deleted and the base template href
  points at the uploads path (site-relative → per-site by construction).
  If uploads mirroring skips `.css` (possible — check the media import
  filter at `src/import.rs` `import_media`), extend it to accept the
  theme-generated css path or copy it explicitly at import.
- **Absolute URLs inside the css**: the file's `url(...)` references
  are absolute origin URLs. Rewrite at import with the
  `url_util::strip_origin` helper from phase 01 → site-relative.
- **Scoped variant**: regenerate `.scoped.css` at import by running the
  existing scoping transformation (find it — it produced the repo's
  `.scoped.css` files; likely a script or the boot.rs asset pipeline).
  Output lands beside the site file; Live Mode path joins site +
  filename instead of the global `/admin/front-css/`.
- **Href mechanism**: base template emits
  `{site_url}/wp-content/uploads/<theme-css-path>` (path from
  `plugin:theme:css_upload_path` setting seeded by the adapter —
  traveltour's is `traveltour/style-custom.css` or similar; verify the
  real uploads path in a site dump during implementation).
- **Missing file**: if a site's dump lacks the custom css → omit the
  link (template `{% if site.theme_css %}`); never fall back to the
  aucoeur copy. Remove `templates/front-css/traveltour-style-custom*`
  from the repo.

## Files to modify

- `templates/theme/traveltour/base_*.html` (phase 03 location) — link
  href → `site.theme_css` guarded.
- `src/admin/plugins/theme_traveltour/` — seed the css path key;
  migrate cleans nothing (no old rows for this key).
- `src/admin/mod.rs` `front_css` route (`:1615-1618`) — Live Mode: if a
  `.scoped` twin of the site file exists, serve it; else keep repo
  fallback for non-custom files only.
- `templates/front-css/` — delete `traveltour-style-custom.css` +
  `.scoped.css` (repo copies).
- New: import-time scoper reuse — wherever `.scoped.css` generation
  lives (locate via `grep scoped` in src/ + scripts/).

## Implementation steps

1. Verify how uploads are mirrored today (import_media filter,
   www dir layout for an existing site); pick carry mechanism.
2. Import: rewrite absolute URLs in the carried css via `strip_origin`;
   generate scoped twin; persist `plugin:theme:css_upload_path`.
3. Template: guarded `site.theme_css` link.
4. front_css route: per-site scoped serving.
5. Delete repo copies; generate all four sites; confirm href targets
   exist and no `aucoeurvietnam.com` remains in emitted css links.
6. `cargo check && cargo test`.
