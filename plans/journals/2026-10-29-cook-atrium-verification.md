## Decisions made under pressure

- **Mobile nav needed four `!important` counter-rules.** WP vendor CSS hides
  `#adminmenuwrap` under 782px, pins `#adminmenu` `position:absolute; top:46px`,
  pins `.wp-menu-image` absolute, and pads `.wp-menu-name` 8px/36px. Every one
  is a counter-important vs cms-overrides/colors.min — documented inline.
- **Icon mask + color needed `!important` twice**: `colors.min` sets glyph
  `color` and later my own `background: currentColor` broke unmapped icons —
  the code review caught it: the base `::before` rule had painted a solid
  square over the fallback woff glyph. Removed; verified `dashicons-smiley`
  still renders `\uf328`.
- **More-sheet became a wrap grid, not a scroll row.** A scroll container on
  `#adminmenu` would clip the same flyouts that `overflow:visible` was
  carefully preserved for. `flex-wrap:wrap` keeps both reachable.
- **18px flyout gap got an invisible `::before` hover bridge** — plain
  `li:hover` alone flickers closed on diagonal pointer paths.
- **Ferris teardown**: `__atriumInit` guarded re-init only; htmx swaps could
  drop `#ferris` while the rAF loop ran forever on a detached node. `tick()`
  now bails on `!ferris.isConnected` and idles when `mobileQ.matches`.

- Postboxes ship no collapse handler in this build — `.hndle` click does nothing.
