# rpress full-repo audit — 2026-10-31

Four parallel reviewers (security / data-correctness / architecture-quality /
plugin subsystem) over ~48k LOC Rust + the PHP bridge. Baseline at audit time:
`cargo check` clean, `cargo test` 109/109 green,
`bash scripts/check-layers.sh` → `layers OK`.

Every finding below was re-verified in source by a second pass; `verified`
means file:line confirmed by code reading, `inferred` means the failure mode
follows from verified code but the runtime trigger was not executed.
Findings are grouped by severity; the remediation plan
(`plans/261031-0450-audit-1031-remediation/`) maps each row to a phase.
